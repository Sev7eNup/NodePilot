## Deutsche Kurzbeschreibung

NodePilot ist ein Open-Source-Werkzeug für Windows- und PowerShell-Workflows. Es läuft in der eigenen Infrastruktur, führt Aufgaben über WinRM ohne zusätzlichen Zielagenten aus und unterstützt den Import von System-Center-Orchestrator-Runbooks.

## Englischer Profiltext

NodePilot is an open-source workflow orchestrator for Windows and PowerShell. Design, schedule and inspect workflows in your own infrastructure. Remote execution uses WinRM without installing a NodePilot agent on target machines. Existing System Center Orchestrator runbooks can be imported and reviewed before use. Source code is available under Apache 2.0.
