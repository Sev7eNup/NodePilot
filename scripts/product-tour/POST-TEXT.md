# Reddit draft

**Title:** I’m building NodePilot: open-source visual workflow automation for Windows

I’m working on NodePilot, a self-hosted workflow orchestrator for Windows. It brings a visual designer, PowerShell activities, execution history and a Live-Ops view into the browser. Remote execution uses WinRM, without installing an agent on each target.

This short tour shows a health-check workflow with parallel branches, its PowerShell editor, step timings and output, the dashboard, live operations and logs. It also shows AI model settings and the identity settings preview for LDAP, Windows SSO and OpenID Connect. The recording uses fictional demo data; it is a product tour, not a performance benchmark.

Source: https://github.com/Sev7eNup/NodePilot — Apache-2.0.

I’d appreciate feedback from people who automate Windows systems: which part of your current workflow would you most want this to make easier?
